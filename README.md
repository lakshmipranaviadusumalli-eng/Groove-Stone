# Grove & Stone

Grove & Stone is a fruit and dry-fruit e-commerce web application that allows customers to browse products, manage their cart, place orders, and track their purchases.

## Features

### Customer
- Home page with seasonal information
- Product categories
- Product search
- Product sorting
- Product details and variants
- Shopping cart
- Pincode delivery check
- Customer signup and login
- Checkout and address management
- Payment options
- Mango season calendar
- Mango waitlist
- Customer account
- Saved addresses
- Order history
- Order details and tracking
- Order cancellation
- Contact form

### Admin
- Admin login
- Admin dashboard
- Product management
- Inventory management
- Order management
- Pincode delivery management
- Mango/seasonal content management

## Technologies Used

- HTML
- CSS
- JavaScript
- Node.js
- REST APIs
- JSON-based data storage
